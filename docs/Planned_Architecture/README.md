# Aurelinx: Planned Architecture and Roadmap (`Docs/Planned_Architecture`)

01. **Purpose:** This directory defines the target architecture, Data Ops pipeline design, Intelligence roadmap, and honest scope boundaries for Aurelinx.
02. **Audience:** Reviewers, contributors, and hiring managers evaluating architectural thinking and future engineering milestones.
03. **Structure:**
    - `01_architecture_blueprints/`: Platform architecture, Bronze/Silver/Gold Data Ops design, and ML/Intelligence roadmap.
    - `02_product_and_ux/`: Landing/workspace UX blueprint and enterprise readiness roadmap.
    - `03_strategy_and_scope/`: Clear separation between current prototype scope and future commercial milestones.
