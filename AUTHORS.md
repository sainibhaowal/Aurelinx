## Becoming a Contributor

1. **Start Small** — Good first issues labeled `good first issue`
2. **Follow Process** — See [CONTRIBUTING.md](CONTRIBUTING.md)
3. **Get Merged** — 1+ merged PR = Contributor
4. **Get Recognized** — Added to this file, CHANGELOG.md, release notes

### Contribution Types We Value
- 🐛 Bug fixes
- ✨ New features (screening, analytics, connectors, UI)
- 📝 Documentation improvements
- 🧪 Test coverage increases
- ♻️ Refactoring & code quality
- 🔒 Security improvements
- 🌐 Localization (i18n)
- 💡 Ideas & feedback in Discussions
